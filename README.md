# cashback-fast

Nền tảng cashback/affiliate với giao diện dark glassmorphism.

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - chạy local dev server
- `npm run build` - build production
- `npm run start` - chạy production build
- `npm run lint` - kiểm tra lint
- `npm run type-check` - kiểm tra TypeScript

## Environment

Copy `.env.example` to `.env.local` và điền các biến môi trường trước khi tích hợp Supabase / OAuth / AccessTrade.
